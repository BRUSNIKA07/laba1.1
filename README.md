# laba1.1
работало 4 руки и левая половина мозга на двоих

Учебный проект, в котором с помощью локальной сети соединяются два компьютера с помощью tcp. С одного компа отправляется запрос на смену фотографии, второй принимает и меняет фотографию.

# Запуск(начало)

git clone https://github.com/BRUSNIKA07/laba1.1.git

pip install -r requirements.txt

Далее для 1 компа main, для второго receiver

Также в папке dist лежат экзешники
